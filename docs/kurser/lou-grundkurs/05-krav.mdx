# Kravställning

Kravställningen översätter verksamhetens behov till villkor som leverantörer kan förstå, uppfylla och konkurrera utifrån.

## Olika typer av krav

Det är viktigt att skilja mellan krav på leverantören, krav på själva varan eller tjänsten och kriterier som används för att utvärdera anbud. När dessa blandas ihop blir upphandlingen svårare att förstå och bedöma.

## Tydlighet och proportionalitet

Ett krav ska vara möjligt att tolka på ett förutsebart sätt. Det bör också vara motiverat av behovet och inte vara mer långtgående än vad upphandlingen kräver.
